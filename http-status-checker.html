How it works: Each URL is checked independently using a Cloudflare Worker. The Worker follows 301, 302, 303, 307, and 308 responses manually, records each Location target, detects loops, and stops after five redirects. It uses HEAD first and falls back to GET when HEAD is rejected or unsupported. The response body is not downloaded or stored.
Limitations and safety: This checks publicly reachable HTTP/HTTPS websites on standard ports 80 and 443. Some firewalls, bot protections, geoblocking, or origin rules may return different results to Cloudflare than to a normal browser or Googlebot. Private/local network targets are blocked. This is an HTTP diagnostic, not a full browser rendering test.

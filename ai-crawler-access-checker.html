AI crawler access results

HTML test: The checker retrieves the initial server response and does not execute JavaScript. It measures readable text, detects a <main> or <article> element, and extracts the title and meta description. Low text volume is a warning signal, not definitive proof that JavaScript is required.
Robots.txt test: Rules are evaluated separately for GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, PerplexityBot, Google-Extended, Googlebot and bingbot. Rules are checked against each URL in the redirect chain, using that URL's host and path.
Important limitations: An Allow result in robots.txt does not guarantee that a crawler can access the page. WAF rules, bot protection, authentication, rate limits, geoblocking and server responses can still block access. The HTML fetch uses the checker's user agent, not each AI crawler's identity; it therefore does not prove that a site serves identical HTML to every bot. Google-Extended is a robots.txt control token, not a separate Google Search crawler.
